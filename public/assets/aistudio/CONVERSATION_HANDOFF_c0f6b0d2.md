### 关键坐标系与渲染规则（极易踩坑，新窗口务必遵守）
1. **角度坐标系（`(sin, cos)` 约定）**：
   - `gunAng = 0°` → 朝正下方（`+y`）
   - `gunAng = 90°` → 朝正前方/右侧（`+x`）
   - `gunAng = 180° / -180°` → 朝正上方（`-y`）
   - `gunAng = -126° ~ -130°` → 朝左上方（搭在右/左肩后方，即肩扛方向）
   - 若将局部点 `(lx, ly)` 绕握柄 `(hx, hyW)` 按 `aimRot`（鼠标瞄准偏移角）旋转，公式必须为：
     ```js
     rxPt = hx + lx * ca + ly * sa;
     ryPt = hyW - lx * sa + ly * ca;
     ```
     （不能用 `+ lx * sa`，否则在 `sin/cos` 坐标系下会朝反方向旋转。）
2. **挥砍三拍帧动画法则（长刀、大剑共用）**：
   - **前摇（F0–F2）**：武器摆出蓄力/起手前摇位置。
   - **出刀帧（F3–F4）**：武器**瞬间**到达劈砍完成后的终点位置，并带出完整刀光拖尾（`slashRetract = 0.0`）；挥砍刀光需从 **3D 透视**出发（如横扫为压扁月牙椭圆，斜斩/重砸为立体透视扇面），带**毛边与灰白渐变粒子感**，且**离刀越远拖尾越细、前缘 (`arcU = 1.0`) 必须严密贴合刀身与刀尖**，不可画布截断。
   - **定格收光帧（F5）**：**武器位置与双臂完全保持不变**，仅刀光从尾端**收回一半**（`slashRetract = 0.50`），随后收招复位（F6–F7）。

## 二、已完成的核心功能与改动详情

### 1. 长刀 / 太刀模组（`katana`）—— 已全部完成并定型
- **尺寸与刀鞘比例**：加长打刀刀身与配套刀鞘，修复开刃方向（弧形亮刃朝外劈砍，刀背朝内），确保不会用未开刃的凹面攻击。
- **待机与移动姿态**：
  - **45° 待机（`WEAPON_IDLES34.katana`）**：刀入鞘插于腰侧，一手叉腰、一手握住刀柄。
  - **走路/奔跑/跳跃**：保持刀入鞘（`sheathed = true`），单手扶握刀柄，不拔刀出鞘。
- **四段连招（`comboCount: 4`, `comboDurs: [0.38, 0.24, 0.24, 0.52]`）**：
  1. **一段（`combo1`, `katanaHoriz3D`）· 拔刀向前横扫**：拔刀瞬间向前平扫，带 3D 扁平月牙刀光（复用并精修右键中间那道 3D 扁平月牙），**前缘 100% 贴合太刀刀身，且整道扁月牙随鼠标瞄准角度 (`aimRot`) 绕握柄同步旋转**。
  2. **二段（`combo2`）· 极速斜上挑** & **三段（`combo3`）· 极速斜下劈**：中间二连斩加快节奏（`0.24s`），上弧/斜劈贴合刀身，避免刀插进地里。
  3. **四段（`combo4`）· 大上段重下劈**：起手节奏略放沉（`0.52s`），大开大合重劈收尾，严格执行“武器定格、刀光收回一半”。
- **右键居合战技（`skill`, `skillDur: 0.88`）**：
  - 刀在鞘中双手蓄力，鞘口吸引汇聚粒子；
  - 0.5s 后鞘口粒子爆发形成一颗白色小星光（`sheathStar`）；
  - 爆发时在人物**正前方**打出一个**独立世界特效图层（`drawKatanaOrbitFX`）**：不随人物后续移动而偏移，包含**三道竖直/环绕半周的撕裂月牙刀光序列帧**并带有**三段独立伤害判定**。

### 2. 特大剑 / 玄铁大剑模组（`greatsword`）—— 已完成重制
- **巨型尺寸重构**：参考用户红色轮廓图（`image_ff198cba.png`），将铁质大剑重塑为全长约 **30 像素**的门板巨剑：
  - 配重长柄 `u = -5.5 .. 1.0`
  - 宽厚护手 `7.6px`
  - 玄铁宽刃 `u = 2.2 .. 24.5`，半宽 `halfW = 3.10`（全宽 **6.5–7px**），带血槽、暗金铭文与亮银重刃倒角。
- **全程肩扛姿态（待机 & 走路/奔跑/跳跃）**：
  - **45° 待机**与**侧面走路/奔跑/跳跃/瞄准**全程扛在肩上（`na = [32, 146]` / `[36, 142]`，`gunAng = -126°` / `-130°`，`shoulderCarry = true`），前手抬至锁骨处握柄，远手自然平衡。
  - 在 `drawCharacter` 图层合成中为 `shoulderCarry` 增加了头部分层遮挡处理（`y < shoulderY` 的头部与面部像素压在剑根前方），使巨剑自然搭在肩膀后上方探出，不遮脸。
- **势大力沉的两段重击连段（`comboCount: 2`, `comboDurs: [0.62, 0.72]`）**：
  1. **一段（`combo1`, `gsColossalUp3D`）· 肩扛卸力·拖地狂风上撩斩**：3 帧重剑下垂拖拽在脚后跟蓄势（`-116° → -56° → -24°`）→ 第 4 帧（`F3`）瞬间以 176° 大仰角从地面向上掀出 3D 宽厚风压月牙满刀光（`gunAng = 152°`, `slashRetract = 0.0`）→ 第 6 帧（`F5`）武器高举定格、刀光收回一半（`slashRetract = 0.50`）。
  2. **二段（`combo2`, `gsEarthShatter3D`）· 狮子奋迅·过肩蓄力崩地重砸**：3 帧双手将巨剑拧至脑后肩背极限（`226° → 238° → 246°`）→ 第 4 帧（`F3`）以 240° 超大跨度重砸入前方地面（`gunAng = 6°`, `crouchStance = true`, `slamBurst = 1.0`），带碎石崩裂与 3D 扇形灰白毛边刀光 → 第 6 帧（`F5`）巨剑钉地定格不动、刀光收回一半 → 随后重新扛回肩上（`-130°`, `shoulderCarry = true`）。
- **右键战技（`skill`, `skillDur: 0.86`, `gsTectonic3D`）· 霸体沉肩·裂地重击斩**：
  - 低姿肩扛聚气后向前斜劈重击，同样遵循 3 拍刀光法则（前摇 → 瞬间劈完满刀光 → 定格收半光）。
