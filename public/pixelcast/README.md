# PixelCast —— 通用像素骨架 + 六个性格角色 + 自主 AI

## 文件
- `pixelcast_demo.html`  单文件演示（双击即可打开）：灰雾场景、6 人自主行动、卡片里循环播放各自的待机动画
- `rig.js`   骨架 + 绘制 + 姿势库（走/跑/冲刺式跑步/起跳/空中/二段翻滚/落地/急停/蹲）+ 6 套性格待机
- `cast.js`  角色数据：外观、配色、性格参数 traits、步态、台词、人物间好感度
- `ai.js`    世界与行为：意图层(性格驱动) → 操控层(自动跳台阶/沟/墙) → 运动层(物理+状态机)
- `skeleton.json`  骨骼定义 + 姿势字段说明 + 全部角色数据，方便导入 Godot 等引擎

## 骨架
15 根骨骼，32x80 网格。比例（对照参考图修订后）：头 5 行（上两行全是头发，脸从第 3 行开始）+ 颈 1 + 躯干 4 + 骨盆 2 + 腿 11（大腿 6、小腿 5）。
侧面动作（走/跑/跳/翻滚）角度以垂直向下为 0、朝前为正。一个姿势 = `{nl, fl, na, fa, tail, lean, bob, head, blink}`。
**待机使用 45° 视角**（`po.v34 = true`）：肩宽 4、双臂分在两侧、两腿并排、头 6 列脸 2 列宽（不画眼睛，右侧不留挡脸的头发）；此时 na/fa 为画面左/右臂，nl/fl 为画面左/右腿，角度在画面平面内（向下为 0，向画面右为正）。待机与侧面动作之间会插一帧转身过渡。
所有角色共用同一套动作，差别只在 build（腿长）、gait（步态）、idle（待机）。

## 六种性格待机（骨架动画各不相同）
| 角色 | 性格 | 待机 |
|---|---|---|
| 林 | 冷静 | 抱臂、慢呼吸、偶尔换重心 |
| 白 | 沉思 | 手托下巴、低头、指尖轻敲 |
| 苏 | 健谈 | 举烧瓶比划、脚尖弹跳、点头 |
| 铁 | 暴躁 | 叉腰、跺脚、叹气 |
| 米 | 胆小 | 抱住自己、缩肩、偷看 |
| 星 | 探索者 | 自然站立、上身呼吸、偶尔环顾（会冲刺、瞬移、蹲行，可穿太空服） |

## AI
traits：soc 社交 / en 精力 / cau 谨慎 / cur 好奇 / pat 耐心（0~1）。
- 发呆、闲逛、看场景物件、找人聊天（对方按好感度和社交倾向决定接不接）、躲开讨厌的人（胆小的跑开并蹲下，暴躁的嘟囔着走开）
- 精力旺的会边走边蹦、聊到兴奋原地跳；宽沟会助跑 + 二段跳
- 台词在 `cast.js` 的 `lines`

## 操作（演示页）
A/D 走，Shift 跑，空格跳（空中再按二段翻滚），S 蹲，Y 向最近的人搭话，1–5/点击切换，T 接管/放开。
"集合对比待机"可把五人排成一排，对比待机动作。

## 新增角色
在 `cast.js` 的 `CAST` 里加一项，并在 `AFFINITY` 里补好感度；新待机动作写进 `rig.js` 的 `IDLES`。
